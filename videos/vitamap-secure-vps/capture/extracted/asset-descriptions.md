# Asset inventory

No assets were captured. This is a **no-capture, typography-and-UI-mockup** video:
every screen (VitaWende landing, the pilot register form, the upload dropzone, the
chat window) is rebuilt in HTML/CSS from the real VitaMap UI source, not from
imported screenshots. Frames are typography-only + hand-built UI mockups; the
`asset_candidates` list is intentionally empty for all frames.
